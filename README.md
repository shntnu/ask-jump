# Ask JUMP

Ask natural-language questions about JUMP Cell Painting metadata.
Jev classifies answerability and reviews SQL generated by GPT-OSS 120B.
DuckDB executes the query against the v0.13 release.
Edit the generated SQL and rerun the review to test Jev's assessments.

The review is advisory, not an authorization boundary or calibrated correctness guarantee.
DuckDB independently enforces read-only access, disabled external access and extensions, a 256 MB memory limit, an 8-second query timeout, and at most 200 returned rows.
The database is downloaded into temporary storage on first use and checked against the release SHA-256.
The application is a public demo; calls consume the connected team's AI Gateway credits.

## Deploy

```sh
npm ci
npm run check
npm test
npx vercel@latest --prod
```

Vercel deployments authenticate to AI Gateway with OIDC automatically.
For local requests, create an AI Gateway key and put it in `.env.local`:

```sh
AI_GATEWAY_API_KEY=your_key_here
```

Then run `npx vercel dev`.

Optionally set `JUMP_DATABASE_PATH` to an existing local v0.13 database to avoid downloading it.
The production deployment uses Vercel OIDC, without a separately stored API key.
Zero Data Retention is not enabled on this Hobby deployment.
